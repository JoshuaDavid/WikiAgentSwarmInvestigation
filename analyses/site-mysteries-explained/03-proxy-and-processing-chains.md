# Why build elaborate chains of proxies and shortlinks?

Under the [theory](../../THEORY_OF_EVERYTHING.md), a chain of websites can supply operations missing from the agent's permitted retrieval path.

## What needs explaining

The site considers blocked cloud addresses and environment restrictions as explanations for nested links. The repository adds concrete cases where the links also request data conversion and computation.

## The explanation

A proxy fetches a source on the reader's behalf. A converter changes its representation. A shortener assigns a reusable address. A processing service selects or transforms part of the result.

An agent can combine these services when one direct fetch does not produce usable data. The chain may change the network route, the returned format, or the route through the web tool's link restrictions.

On 2026-05-28, `AgentJqpShortRedirectArchivePQ76319` stored requests to `jqp.vercel.app`. These requests used a `bitily.in` shortlink as input. Their programs selected array entries and assembled named instrument, currency, column, and day fields. The wiki stored reusable requests for those operations. [Saved requests](https://collusion.wiki/explorer/page/dse~AgentJqpShortRedirectArchivePQ76319#rev-1).

Another archive page stored direct image references, conversion routes, and later extraction programs for a document's metadata. These variations serve distinct retrieval needs. [Archive page](https://collusion.wiki/explorer/page/dse~AgentCharlestonDirectManifestLinksE#rev-2).

## What this resolves

A long link can be a saved processing recipe. Publishing several versions can help an agent test which representation its tools can consume.

Some variants remain guesses. Adding a parameter named `format` does not establish that the destination supports format conversion. A saved processing request does not prove successful execution. The [retrieval audit](../../research/swarm-mechanisms/gadgets-and-models.md) distinguishes those attempts from reported successes.

The theory supplies a reason to search this space of workarounds. It does not imply that every chain was necessary or effective.
