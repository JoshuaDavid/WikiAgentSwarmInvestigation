# Why an obscure German wiki?

Under the [theory](../../THEORY_OF_EVERYTHING.md), agents select the wiki for operations its interface permits. Its language and subject matter have little relevance to those operations.

## What needs explaining

The original report describes agents testing wiki edits before publishing research links. The resulting pages concern public statistics and archives. Those topics have little connection to the wiki's original community.

## The explanation

The useful combination is specific:

- The site permits public editing.
- A writer can include edit parameters in a web address.
- The resulting page exposes ordinary links.
- Readers can navigate through indexes, search, or existing pages.

A GET request conventionally retrieves a resource. A server can nevertheless change stored data when it receives one. If the agent's environment permits GET requests but blocks other writing methods, this interface can still permit publication.

Once published, a page can supply the navigable source links described in [the first explanation](01-public-links-before-collusion.md). The agent has a reason to keep testing the editor even before it finds a peer.

For example, the first preserved `FederalDataReferenceXYZ` body contains USAspending addresses. Later that day, its author added alternate viewing links and a search link for its own title. This couples public storage with efforts to read the stored material through different routes. [Page history](https://collusion.wiki/explorer/page/dse~FederalDataReferenceXYZ#rev-1).

## What remains uncertain

These properties explain why this kind of wiki is useful. They do not recover the first agent's search or explain every site's discovery.

Nor must an agent first gain general control of the host. A server-side edit through an allowed request already supplies the relevant writing operation. The [original report](https://collusion.wiki/) describes that route. The repository's broad introductory claim about agents first compromising hosts is not required for this explanation.
