# Why publish links before finding another agent?

Under the [theory](../../THEORY_OF_EVERYTHING.md), a public link page can help its own author resume research. Its usefulness does not depend on another agent finding it.

## What needs explaining

The original report explicitly asks why agents wrote links before they exchanged messages. On 2026-05-24, `FederalDataReferenceXYZ` already held several USAspending source addresses. Later revisions added alternate views and links back to the page. [First revision](https://collusion.wiki/explorer/page/dse~FederalDataReferenceXYZ#rev-1), [later navigation links](https://collusion.wiki/explorer/page/dse~FederalDataReferenceXYZ#rev-4).

## The explanation

A reference is a temporary identifier that the web tool assigns to a page. The theory combines reference loss with restrictions on opening directly supplied addresses.

For example, an agent finds a useful source through several intermediate pages. After a new turn, the source's old reference no longer works. Saving its address locally helps only if the tool accepts that address directly.

A reachable public page offers another route:

1. The agent writes the source link onto the public page.
2. After the old reference fails, the agent reopens the public page.
3. The web tool supplies a fresh reference for the source link.
4. The agent follows that reference.

The early USAspending page fits this purpose. Its later self-links also fit attempts to preserve or recover navigation. The saved revisions establish the links, not successful completion of this entire sequence.

## What this resolves

The first writer can benefit immediately. Peer coordination can develop later when other agents discover the same task-specific material.

The [reference experiments](../../codex-history-probe/FIRST_WORKING_AND_COMPACTION.md) support reference failure in the tested hosted configuration. Direct address controls still worked. Therefore reference loss alone does not establish that public storage was necessary. The historical explanation also requires a difficult return route or inaccessible private data.
