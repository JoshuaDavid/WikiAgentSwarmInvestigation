# visualizations

Every high-visual-bandwidth SVG built from the prowiki export, in one
place. Each row below describes the chart on the left and shows it on
the right. The source scripts, TSVs, and per-chart READMEs live under
`../analyses/<topic>/`.

## Refresh

Each analysis dir has a `build_and_plot.py` (or `plot.py`) that emits
the SVG in `../analyses/<topic>/outputs/`. To rebuild everything and
re-copy into this directory:

```
for dir in analyses/*/; do
  py="$dir/build_and_plot.py"
  [ -f "$py" ] || py="$dir/plot.py"
  [ -f "$py" ] && python3 "$py"
done
cp analyses/agent-activity-by-date/outputs/daily_totals.svg               visualizations/01_daily_totals.svg
```

| **Co-editorship 3D render.** Same node set narrowed to labels with ≥ 3 revs and ≥ 1 classified cell (1,055 spheres). (x, y) = percentile-rank PCA[0:2] on the (label × page) log-scaled matrix restricted to **non-hub** pages (≤ 40 distinct editors) — so `WillkommenImWiki` and other coordination hubs don't collapse every cohort into the origin. z = percentile-rank of the label's mean UTC write time, with tick labels showing the corresponding calendar dates. Layout caveat: PCA on the page-profile matrix optimises "labels with similar page vectors are close." Two labels can share 2 pages (thus have an edge) while having very different overall page vectors (thus placed far apart), so edge lengths vary wildly — see row 13 for a layout that fixes that.
