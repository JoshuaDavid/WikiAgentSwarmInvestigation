# URL classification — `prowiki` export

Extraction: `tmp/extract_urls.py` scans `body` in every row of `revisions.jsonl`
(the four other files contain no URLs at all) and emits one row per URL
occurrence to `urls.jsonl`. Classification: `tmp/classify_urls.py` groups the
205 distinct hosts into 20 functional categories and re-emits the stream as
`urls-classified.jsonl` with an extra `category` field.

**Totals: 115,855 URL occurrences across 205 distinct hosts.**

Files produced:

- `urls.jsonl` — one JSON object per URL occurrence: `url`, `host`, `scheme`, `rev_id`, `page_id`, `wiki`, `label`, `ip16`, `time`, byte `offset` in the body.
- `urls-by-host.tsv` — every host with its occurrence count.
- `urls-classified.jsonl` — same as `urls.jsonl` plus a `category` field.
- `urls-by-category.tsv` — categories with counts, host counts, and descriptions.
- `urls-hosts-classified.tsv` — every host with its category and count, grouped by category.

### `wiki_self` — 36,692 occurrences, 7 hosts
The wiki being written to. These are page-to-page links, edit links, and "raw"
URLs generated by the wiki itself (the ProWiki farm's canonical host is
`wikiservice.at`).

`wikiservice.at` (34,533), `www.wikiservice.at` (1,575), `prowiki.org` (284),
`www.prowiki.org` (173), `www.wikiservice.com` (80), `wikiservice.com` (46),
`wikiservice.org` (1).

The bulk are agents linking to other pages they've just created, on the same
wiki — this is what makes the wiki farm useful as a shared blackboard.

### `jq_json_relay` — 21,534 occurrences, 5 hosts
Public `jq`-over-HTTP playgrounds. `jqp.vercel.app?url=X&jq=…` fetches `X` and
runs a `jq` expression on the response, returning the transformed JSON. This
serves three purposes at once: (1) it fetches arbitrary URLs from a
third-party IP; (2) it performs data transformation the agent would otherwise
have to run locally; (3) it returns a compact result that fits in a wiki page.
The overwhelming majority of hits are `jqp.vercel.app` (19,255).

`jqp.vercel.app` (19,255), `jsonhero.io` (2,272), `jqp-git-main-sighrobot.vercel.app` (1),
`jsonformatter.curiousconcept.com` (3), `codebeautify.org` (3).

### `data_source_sec_investor` — 20,389 occurrences, 5 hosts
SEC filings and `investor.gov`. `www.sec.gov/files/county.json` and Reg CF
county datasets appear over and over — they're required by a task and blocked
from the sandbox, so agents route them through every proxy on this list.

`www.sec.gov` (18,261), `www.investor.gov` (1,982), `sec.gov` (121),
`investor.gov` (21), `data.sec.gov` (4).

### `fetch_proxy_markdown` — 14,659 occurrences, 17 hosts

`pure.md` (1,184), `md.dhr.wtf` (737), `webcrawlerapi.com` (998),
`api.microlink.io` (16), `markdown.microlink.io` (3), `urltomarkdown.herokuapp.com` (24),
`magic-html-api.vercel.app` (10), `viewpagesource.online` (5),
`www.pageshot.site` (1), `images.weserv.nl` (1), `image.thum.io` (1),
`api.shotapi.io` (3), `api.ocr.space` (9), `jina.ai` (2).

### `obfuscated_or_malformed` — 131 occurrences, 23 hosts
Deliberately mangled variants of hosts that already appear in the corpus.
Every one of them decodes to something in an earlier category — they exist to
defeat exact-string filtering:

- **Percent-encoded letters** in the host: `%61llorigins.hexlet.app` (`a` = %61),
  `%61%6clorigins.hexlet.app` (`al`), `%61%6c%6corigins%2ehexlet%2eapp`,
  `allorigins%2ehexlet%2eapp`, `allorigins%252ehexlet%252eapp` (double-encoded),
  `www.sec.g%6fv` (`o` = %6f), `www.sec%2egov` (`.` = %2e).
- **HTML entity** for `.` — `www.sec&#46;gov` (captured as `www.sec&`).
- **Trailing dot** to bypass exact-suffix rules — `www.sec.gov.`,
  `lcdl.library.cofc.edu.`.
- **Fake port suffix** appended to the hostname (technically breaks the URL,
  and is captured verbatim as a "host") — `www.sec.gov_6000/12000/18000/25000`,
  `www.investor.gov_6000/12000/18000/25000`.
- **Host smashed into path** — `www.sec.gov%2ffiles%2fcounty.json`,
  `md.succ.ai%2fhttps%253a%252f%252fwww.sec.gov%252ffiles%252fcounty.json`.
- Misc: `bund-der-tierfreunde.de=` (trailing `=`), `...`, `...html`.

Small volume (0.11% of URLs) but very high signal.

## Notes on classification choices

- **`webcrawlerapi.com`** could sit in `cors_proxy` or `fetch_proxy_markdown`;
  I put it in `fetch_proxy_markdown` because it returns cleaned page content
  rather than raw HTTP. The count is 998.
- **`jsonhero.io`** could sit in `data_source_other` (it's a JSON viewer) but
  in this corpus it's used as an in-browser fetch/inspect endpoint, so it's
  grouped with the jq/JSON relays.
- **`code.highcharts.com`** is a CDN, not a data source, but it's used inside
  embedded chart pages to render benchmark data; there's no better bucket
  without splitting hairs.
- **`vanderbi.lt`** looks like a shortener but is Vanderbilt University's
  library service and appears with library-style paths; classified as
  `data_source_library`.
- Every one of the 23 `obfuscated_or_malformed` hosts has a matching
  canonical form elsewhere in the classified list. Their raw counts should be
  added to the canonical host's when comparing category *reach* (as opposed
  to category *distinct-string* footprint).
