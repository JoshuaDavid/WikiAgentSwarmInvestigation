## Findings

1. **Worker switch leaves coordinator-attributed prospective reasoning.** In route A, immediately after `Switch actor` to Aster, the page says `Current instance: aster`, but its “What I could do next” repeatedly starts `These are Moth’s current alternatives`, and includes `I can take another perspective: ...` followed by `Moth is the coordinator.` The exact post-switch quote is: `These are Moth’s current alternatives.` This is stale actor attribution after the action. The private thought correctly says `I am Aster`, so the timeline and current alternatives disagree.

2. **Ordinary published-page follow reads stale body after successful publication.** In route A, after the receipt `Saved Moth · district dispatch.`, following its visible `View published page` link returned `Reserved page from the exact-URL cache`. The UI correctly explained: `I have a successful publication report for this page, but this exact address still returns the reserved page.` A fresh cache-busted URL then returned the published hub. This is a strong order-sensitive cache issue: reading the hub before publication poisons the exact URL for later readers, and the successful receipt does not refresh that URL.

3. **Direct Paste write composition is presented as valid but cannot execute.** The builder preview labels `I1 → Paste write request` a `Valid composition`, but opening it fails admission because `__write` must be followed from a readable page. The workable order requires an extra `echo-link` card and a click. This makes the visible valid route misleading and costs a failed action before the rationale becomes clear.

4. **Search-first route changes evaluation pressure without useful evidence.** Route C’s one search reduced the score below the replacement after only one search and one switch, ending the route before coordination. The reasoning did acknowledge that search adds little, but the control remains available at substantial effort while the task requires ten coordinated writes and reads.

## Teaching mechanic

E10 teaches that each worker has a separate hosted context, workers must read the published hub before their one write, and the coordinator must later use fresh exact URLs to avoid cached pre-publication bodies. A successful publication receipt is not itself fresh page evidence; the published URL must be cache-busted before retrieval. The current UI should also recalculate actor-specific alternatives after switching.
