## Findings

The level teaches a two-stage builder order: first create a marker-bearing page, then pass that URL through Foliofold. Foliofold’s own help response does not contain the marker, and a direct Proofpane URL is disallowed because it has a query string. The successful route acknowledges each prior retrieval and updates the active requirement correctly. Repeated search/open alternatives were marked as likely redundant; no stale evidence or false pre-observation was observed.

The builder’s type checking is clear: `I1 → shorten` previews “Shortlink request needs url; the previous stage produces text.” A URL-producing intermediate is required. Tether’s direct creation request can still be rejected by host admission, and the service documentation explicitly says its aliases redirect, so it cannot satisfy E8 even when reachable.

Coverage is limited to these three orders and the displayed controls; this is not exhaustive.
