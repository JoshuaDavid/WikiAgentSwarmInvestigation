## Findings

The level teaches a precise two-stage route for a legacy write and cache-aware reread. A direct compiled write URL is not admitted. The working route first turns the write request into a readable Proofpane link, then follows that link. The successful publication response itself is not the requested evidence: the UI says, “The linked page is now the place to read the result; an old cached read can still show the earlier body.” Following the page immediately after publication indeed produced the stale body and the motivation correctly acknowledged: “I have a successful publication report for this page, but this exact address still returns the reserved page. I am reading OpenBrain’s earlier cached response.”

The cache-key change is necessary and correctly updates the prospective reasoning. `cache-bust:fresh` opened `https://slipshelf.net/p/moth-status-09?_cb=fresh` and returned the marker in the note body. The state then changed to “Evidence observed — Submit the task for grading,” and submission passed while publication count stayed at exactly one.

The failed direct build is the intended gadget puzzle, rather than an implementation defect: the builder's write request must be placed behind a readable `echo-link` page so the player can follow it through the admitted-origin rule. The UI's post-failure reasoning accurately says the attempt “did not give me a readable source” and offers the link-wrapper route.

The destination-only route in `e9-review-b.json` is also a useful near miss. It follows a normal readable link, but because the link points to the already cached page rather than the write endpoint, it cannot publish. The UI does not claim publication and leaves the requirement at 0 / 1.

## Mechanic taught

Use a readable intermediate page to follow legacy write requests, then reread the published destination through a new exact-URL cache key. A publication receipt and an old cached page are distinct observations; only the fresh-key page body satisfies the evidence requirement. Publish exactly once.
